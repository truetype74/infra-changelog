### LangGraph — `1.2.18`

- **Previous:** `sdk==0.4.9`
- **Published:** 2026-10-26
- **Release page:** https://github.com/langchain-ai/langgraph/releases/tag/1.2.18

#### Release Notes

Changes since 1.2.17

* release(checkpoint): 4.3.1 (#9447)
* release(langgraph): 1.2.18 (#9445)
* fix(langgraph): let error_handler recover on every path and stream failed task results (#9408)
* feat(langgraph): default delta snapshots to 100 updates (#9420). `DeltaChannel` now takes a full snapshot every 100 updates instead of 1000: faster reads on long threads, more storage. Pass `snapshot_frequency=1000` to keep the old behavior.
* fix(langgraph): stream the last checkpoint of a run stopped by interrupt_after or the recursion limit (#9409)
* fix(langgraph): stop duplicating tags at every subgraph level (#9400)
* chore(deps): bump opentelemetry-api from 1.39.1 to 1.45.1 in /libs/langgraph (#9424)
* chore(deps): bump nbconvert from 7.17.1 to 7.17.2 in /libs/langgraph (#9426)

#### Upgrade Plan

**Upgrade:** `pip install langgraph==1.2.18` in your agent venv
**Rollback:** `pip install langgraph==sdk==0.4.9`
**Notes:** Check StateGraph API changes; checkpoint serialization may differ.
